# Java Interview Practice

Repository dedicated to practicing programming problems commonly used in technical interviews for **internship and junior developer positions**.

The exercises are implemented in **Java**, with a focus on problem-solving, data structures, algorithms, and familiarity with the Java standard library.

## Topics

* Arrays
* Lists
* Strings
* HashMap / HashSet
* Two Pointers
* Stack / Queue
* Searching
* Sorting
* Basic algorithmic complexity

## Problems

| # | Problem                         | Topic             |
| - | ------------------------------- | ----------------- |
| 1 | Two Sum                         | HashMap / Array   |
| 2 | Contains Duplicate              | HashSet           |
| 3 | Valid Anagram                   | Strings / Sorting |
| 4 | Valid Palindrome                | Strings           |
| 5 | Best Time to Buy and Sell Stock | Array             |

More problems will be added progressively.

## Goal

The goal of this repository is not to collect solutions, but to develop the ability to:

* Understand a problem quickly
* Break it down into smaller steps
* Choose appropriate data structures
* Write clean Java code
* Analyze basic time and space complexity
* Improve solutions when necessary

## Language

**Java 21**
